### 2. Теория

<b>Свёрточная нейронная сеть (CNN)</b> — архитектура нейронной сети, предназначенная для обработки данных с пространственной структурой (изображения, сигналы). Основные слои:

* <b>Свёрточный слой (Conv2d)</b> — извлекает признаки с помощью обучаемых фильтров (ядер). Параметры: число фильтров, размер ядра, шаг (stride), дополнение (padding).
* <b>Слой подвыборки (MaxPool2d / AvgPool2d)</b> — уменьшает пространственную размерность, снижает число параметров и обеспечивает инвариантность к сдвигам.
* <b>Функция активации (ReLU)</b> — вносит нелинейность.
* <b>Полносвязный слой (Linear)</b> — выполняет финальную классификацию на основе извлечённых признаков.
* <b>Dropout</b> — регуляризация для предотвращения переобучения.

<b>Датасет MNIST</b> содержит 70 000 изображений рукописных цифр (60 000 — обучающая выборка, 10 000 — тестовая), размер каждого изображения 28×28 пикселей в оттенках серого, 10 классов (цифры 0–9).
